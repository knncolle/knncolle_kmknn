template<typename Index_ , typename Data_ , typename Distance_ , typename KmeansFloat_ = Distance_>
auto knncolle_kmknn::load_kmknn_prebuilt ( const std::filesystem::path & dir)

Helper function to define a knncolle::LoadPrebuiltFunction for KMKNN in knncolle::load_prebuilt_raw().

To load an KMKNN index from disk, users are expected to define and register an KMKNN-specific knncolle::LoadPrebuiltFunction. In this function, users should call load_kmknn_prebuilt_types() to figure out the saved index's KMKNNDistance_, KMKNNIndex and KMKNNData_. Then, they should call load_kmknn_prebuilt() with the appropriate types to return a pointer to a knncolle::Prebuilt object. This user-defined function should be registered in load_prebuilt_registry() with the key in knncolle_kmknn::save_name.
